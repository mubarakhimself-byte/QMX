# Contracts

What the host offers the UI and the apps, in files a page, a planner or the ship kit can read
without starting the host.

| File | What it is | Made how |
|---|---|---|
| `host-openapi.json` | The OpenAPI schema of the one REST app the host serves on This PC: every route, its operation id, parameters, request and response schemas | Generated by `python tools/contract_dump.py` |
| `apps.json` | Each first-party app (`qmx-agents/apps/*/app.toml`): `version`, `kind` and its `operations` (name, approval, reversibility, state, description). An app operation is called through `POST /api/apps/{app_id}/tools/{tool}` | Generated by `python tools/contract_dump.py` |
| `events.md` | The Server-Sent Event topics under `/api/events/{topic}`: payload fields and who writes each | By hand, from the code |
| `CHANGELOG.md` | What changed for the UI, one block per checkpoint (written by the docs step once it exists) | By hand |

**The two JSON files are generated. Never edit them by hand.** After changing a route, a REST row
(`rest=(...)` on `ControlService`), a router or an `app.toml`, run `python tools/contract_dump.py`
and commit the result with the change. CI's lint job runs `python tools/contract_dump.py --check`,
which fails and names each operation added, removed or changed when a file is stale.

`host-openapi.json` is built in-process on a throwaway home with a test bearer, so it needs no
running host and no credential. It covers role `pc` (This PC). Left out: the Library hub's routes,
which a `server` host mounts, and the catch-all 503 that replaces `/api/data/*` when the market door
did not open. The MCP mount at `/mcp` is for agents and has no OpenAPI entry.

## Errors

A refusal comes in one of three shapes. A client must read all three.

| Shape | Where |
|---|---|
| `{"error": {"code": "...", "message": "..."}}` | Control rows (`ControlError`, app `AppError`, `RemoteError`), and a missing or wrong bearer (401, `code: "unauthorized"`) |
| `{"detail": ...}` | FastAPI's own (`HTTPException` and request validation, 422): the data card, backups, keys, connect, templates, webhooks |
| `{"ok": false, "code": "...", "message": "...", "next_step": "..."}` (and `value` when there is one) | `POST /api/units/promote` |

# DR5A findings: backlog

- DR5A: `E/triggers/ticker.py` does not pass connection readings to `preflight`, so the new connection check is inert in the live scheduler. `preflight` reads `connections=` or `connection.<id>.word` settings keys; neither is produced today. The fix is one line in `ticker.py` (`connections=heartbeat.connection_words(self.ctx.home)`) but that file is outside DR5A's Files block. Evidence: `E/triggers/preflight.py` `connection_fault`; `ET/test_connections_health.py` passes the mapping itself.
- DR5A: connection ids are unique within a provider, not across the Settings `connections` list. Two providers may each hold `demo`, and the heartbeat reading map is keyed by connection id alone, so a reading can be ambiguous. Making ids node-unique would change the existing `qmx-broker` fixture and every stored row, so DR5A left the check where it was. Evidence: `BR/models.py` `Broker.valid_connections`; `heartbeat.connection_words`.
- DR5A: a UI or copilot that still reads `settings_get("brokers")` sees the pre-DR5A shape only. `legacy_brokers` in `QX/service.py` projects the old keys and drops `kind`, `scope`, `home`, `capabilities`, `reported_limits` and `licence`, so the Connections screen must read `connections` (the UI session's work). Evidence: `QX/service.py` `LEGACY_*_KEYS`.
- DR5A: the `connections-health` template script imports `qmx_broker`, which `qmx-engine` does not declare as a dependency. It works only in a workspace sync with `--all-packages` or on a host where `qmx-broker` is installed. Evidence: `E/templates/connections-health/scripts/health.py`; `ET/test_connections_health.py` does not run the script.
- DR5A: the MT5 declaration ships without a probe or a session, so an `mt5` connection reads `needs_you` with `probe_missing` until DR5B lands its terminal home. That is intended for this split but invisible in the plan's own words.
- DR5A: `slowdowns` is process-local; a host restart forgets every `slowed_until`, so the next call after a restart can hit a provider still pacing that address.

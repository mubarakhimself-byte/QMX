# Independent Sol exploration — canonical QMB replay composition builder

The remaining builder is authorized application work. Existing typed services provide a concrete composition path; missing decoders and caller wiring do not justify inventing policy defaults or narrowing execution to a source callback.

Existing sequence:

1. QMB-owned host composition opens configured `EvidenceStore`/`WorldStore`, `RegistryPersistence` (`qmf/registry/persistence.py:391`), and reads fingerprint-addressed registrations using `load_record(..., for_world=...)` (`:521`). `LoadedRecord` (`:255`) contains checked kind/version, deeply immutable body, parents and stable/persisted fingerprints; optional occurrence provenance is separate. Decode CT22/27 through `qmf.risk.templates.BookDefinition.try_create` / `BmsDefinition.try_create`, verifying exact kind/version and reconstructed identity. A registry cite alone is not a typed policy.
2. Construct the existing immutable `PassiveHub`/`AsOfSet` and `RegistryReadPort.try_create` (`qmb/registryread/port.py:108`) with explicit stale-evidence severity. Use `materialize_book_fragment` and `materialize_bms_fragment` (`config/fragments.py:270`, `:286`), then `compile_run_config` (`config/compiler.py:494`). This compiler already mints the REPLAY CT28 `ReplayBinding`, including starting capital and seed-override rating. Do not invent a second binding path.
3. Resolve the persisted replay request through `host/replay_request.py` against the configured raw root and the already registered ExperimentSpec's CT12 data reference; preserve split role, holdout policy, immutable source and exact CT33 manifest selection. Ordinary `invoke_backtest` (`doors/cli/tree.py:956`) explicitly refuses caller-supplied ExperimentSpec at `:990`; lookup an existing authorized reference for a recorded request rather than minting one as an incidental ordinary backtest side effect.
4. Bind canonical execution adapters with `bind_execution_ports(config)` (`execution/binder.py:235`). Construct `BookAdmissionContext.try_create` (`host/book_handler.py:95`) using exact policy values and the config's exact binding. Execute via `execute_recorded_replay_request` (`host/replay_execution.py:51`) with canonical durable `JournalReader`/`JournalWriter` and governed `LedgerSink`. The service runs actual Book execution, CT13 recovery, CT29 and CT32; it is not yet evidence of a complete CLI child path.

A minimum explicit operator binding file should name: format version; registry/raw/output roots; request fingerprint; existing ExperimentSpec fingerprint and split/holdout authorization; pinned registry as-of and stale-evidence severity; Book/BMS fragments and run-spec/invocation layer values; exact instrument metadata identity including scale and ValueFactor; requested R, money-per-R, money scale, lot step and cap; exact execution target and result label; registered exit-logic reference/module selection; complete intent-code close-reason and order-policy maps; fingerprinted rollover calendar and financing schedule; allocated CT13 WriterId/stream. Reject unknown or missing fields and binary floats. Resolve byte/fingerprint references from configured stores and revalidate before effects. Keep these application schemas in QMB host/config, consumed by QMB CLI and worker; a QMA composition root is not the canonical QMB builder.

`BookOrderPolicy` (`host/book_handler.py:339`) supplies typed order type and applicable exact price/trail/liquidity/fee fields; no code-map fallback exists. `RolloverCalendar` (`execution/financing.py:141`) is only a protocol with four methods, not a concrete adapter. An immutable explicitly declared broker calendar adapter remains implementation work: it must preserve venue/timezone/rollover/holiday identity, rather than silently supply UTC, an arbitrary rollover time or empty holiday coverage. Existing ratified CT22/27 sections determine owned policy; arbitrary Python callable injection or raw JSON maps are not a substitute for decoding them.

These exact paths and the ordinary-backtest/ExperimentSpec distinction were sent to the execution owner. No product source was edited; this exploration does not approve builder source, CLI execution, provider connectivity or optimization closure.

## Mismatches the engine architect should fold

1. Engine AD-14 names kinds `workflow_version` and `test_report` as separate kinds. In the Library a version is an object of the `workflow` item (identity = content), so **`workflow_version` is not a kind**: `(workflow_id, semver, content_hash)` maps to `(item_id, fields.semver, object_id)`. `test_report` exists as `test-report`.
2. Engine AD-14's edge set is covered; `consumed_by` reads as the reverse of `consumed`, and `archived_as` is an at-birth relation on the replacement object plus the item-state entry.
3. Engine AD-26 "`main` moves only by his click" is kept **for challengers only** (AD-18); every other workflow output fast-forwards under the workflow's `publish` rule.
4. Engine AD-18's scope caps and snapshot rendering are engine behaviour; the Library only stores rows and serves `search_runs`/`find_by_intent`.
5. The word "hub": say "the Library Hub" (`qmx_hub`) and "the node inbox" (DEC-0188).

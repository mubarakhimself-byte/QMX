# Library requests

What the engine needs from the Library architecture (`architecture/library-and-data/ARCHITECTURE-SPINE.md`, the Library agent's design) beyond what its AD-15 already gives. Each row cites the Library AD it touches, states the smallest form, and says what the engine does until it is granted. None of these changes the Library's paradigm; they add kinds, ref namespaces, one annotation, one field and two verbs.

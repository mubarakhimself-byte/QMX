# Library requests

What the engine needs from the Library architecture (`architecture/library-and-data/ARCHITECTURE-SPINE.md`, the Library agent's design) beyond what its AD-15 already gives. Each row cites the Library AD it touches, states the smallest form, and says what the engine does until it is granted. None of these changes the Library's paradigm; they add kinds, one ref namespace, one annotation and two verbs.

| Id | Request (smallest form) | Why the engine needs it | Library AD touched | Until granted |

| L1 | Add kind **`memory-row`** to the roster: identity `scope, tag, intent_key?, when_to_use, content, refs[]`; annotations `keywords[], confidence, f, u, source_run_ids[], learned_at, occurred_at`; tag ∈ `built, lesson, dead_end, do_not_retry, negative_result, procedure, preference`; relations `mentions`, `derived-from → workflow-run`, `replaces → memory-row`. `f` and `u` are annotations so updating them mints no version. | Engine AD-18: memory evidence lives in the Library; the provider is only an index.

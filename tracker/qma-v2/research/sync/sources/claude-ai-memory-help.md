# Claude memory (account level), excerpts

- Memory is shared between Chat and Claude Cowork when Cowork runs in the cloud; Cowork sessions that run locally on your computer don't use memory.
- Turn memory on or off for your account: Settings > Your Claude > "Memory from chats" (older layout: Settings > Memory > "Generate memory from chats").
- Search of past chats has its own toggle: "Search and reference chats".
- Turn off memory for a single chat: from the "+" menu before the first message; nothing from that chat is saved to memory; the setting can't be changed once the chat starts.
- Export: Settings > Your Claude > "Manage" next to "Your memory" shows memory "exactly how Claude sees it"; import by adding text in the same place.

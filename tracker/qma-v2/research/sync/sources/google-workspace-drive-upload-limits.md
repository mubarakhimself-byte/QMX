## Google Workspace storage limits

Google Workspace storage is shared between Google Drive, Gmail, and Google Photos. Learn how storage use is calculated.

The amount of storage for each user depends on your Google Workspace edition. Most Google Workspace editions have pooled storage. Pooled storage is indicated in the following tables as total storage or a storage amount times the number of End User licenses.

Pooled storage is granted in stages:

- At the time of purchase, you get part of your storage.

- Your storage increases to your total storage limit after you make a $30 USD payment for your subscription.

- You may make a manual payment or pay early to be granted all storage faster. It can take up to 72 hours after a payment for your storage to increase.

## Drive upload & copy limits

Each user can upload and copy 750 GB to Drive within 24 hours. Users who reach the 750-GB limit can't upload or copy more files until the limit refreshes. The limit refreshes within 24 hours.

- You can upload and synchronize files up to 5 TB in size. Only the first file that breaks the limit completes uploading.

- Files larger than 750 GB can't be copied. Instead, download the file and then upload it.

## Drive file and folder limits

### Account item limit

Each user can have up to 500 million items that were created by that account.
When the item limit is reached, the user can no longer create or upload items in
Drive. They can still view and edit existing items. To create
files again, they must permanently delete items or use a different account.

What counts toward the item limit:

- Items created or uploaded by the user in Drive

- Items created by the user but now owned by someone else

- Items in Trash

- Shortcuts

What doesn't count toward the item limit:

- Permanently deleted files

- Items shared with the user but owned by someone else

- Items owned by the user but created by someone else

### Folder item limit

A folder in Drive that isn't in a
shared drive 
can have up to 500,000 items directly in it. This item limit doesn't apply to
the root folder of My Drive.

The following items count toward this item limit:

- Folders, but not the number of items in those folders

- Any file stored in Drive, regardless of file ownership

- Shortcuts—each
shortcut counts as a single item in a folder, even if the item it points to
isn't in that folder

Example 1: Counting files and child folders

In the following hierarchy, Folder A has 4 items directly in it, and
Folder B has 2 items directly in it:

Folder B

Example 2: Child folder contents don't count toward the parent folder's item limit

Items in a folder count toward the 500,000-item limit for that folder, but items
inside child folders don't count toward the parent folder's item limit:

- My Drive

- Folder C has 300,000 items directly in it, including Folder D
and Folder E

- Folder D has 400,000 items directly in it

- Folder E has 200,000 items directly in it

Here, Folder C contains 300,000 items. The contents of Folder D and
Folder E don't count toward the item limit for Folder C.

### Folder nesting depth limit

My Drive folders can be nested up to 100 folders deep, including the parent
folder. A parent folder can contain a nested folder, which contains another
folder, and so on up to 100 levels. In the 100th folder, users can add files and
shortcuts, but not additional folders. This limit doesn't apply to items that
are
restored or
migrated to another account.

## Administrator controls

- Google Drive: When you turn on the Drive service in the Admin console, your users can upload and sync any file to their accounts.

- APIs: Customers can use an API to add, edit, and remove files in batch, as well as to manage and generate information about their users' documents (but these activities don't generate quota usage information at this time). For example, administrators can use the API to upload a large number of files and share these files with all users in their domain. Learn more about the API upload feature.

- API storage quotas and service accounts: Standalone service accounts that use a client_email identity don't have personal Drive storage. If users try to save to their My Drive, they get a 403 error. If you're using an API to store files, set up a shared drive with supportsAllDrives=true or set up domain-wide delegation.

- Upgrade storage: If a user reports an "out of storage" notification in Drive, you rarely need to contact support. Instead, switch the user's storage limit in the Admin console to resolve the issue.

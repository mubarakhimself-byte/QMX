## Techniques run, in order

1. **Morphological Analysis.** Parameters = the chassis organs; options = components. The table below is the matrix; every hybrid in the deliverable is one path through it.
2. **Concept Blending.** resilience4j's half-open state blended with R9's memory ceiling and MQL5 23315's probe → H11. Kubernetes spec/status blended with MT5's read-only inputs → H01.
3. **Forced Relationships.** Bevy's required components forced onto the halt slot → H19. The CSS `!important` reversal forced onto the floor → H36. Terraform's stale plan forced onto his click → H46.
4. **Cross-Pollination.** Banks' limit hierarchies (RiskMetrics), SRE burn rates, Envoy outlier ejection and Simulink forwarding tables crossed with QMX's hook, journals, kill switch and identity table → H38, H41, H12, H43.
5. **Trait Transfer.** The Book's traits (container, budget share, daily brake, compounding boundary) transferred one by one onto tags, the portfolio config and burn-rate tiers → H40, H41, H42.
6. **Evolutionary Pressure.** Selection rule: a variant survives only if exits stay unblocked, the unit's record survives the change, and a weak but real edge still pays. Bred from H45 (rollout) and H50 (proposal door): the bandit-among-approved-versions variant (H48, kept wild), the tighten-only door with expiry release (H50), the read door (H49). Variants that died: an agent-driven loosening path (breaks "only he promotes"); a profile that replaces the kill switch (breaks C21); a per-unit floor (breaks one-floor and idle-money findings).
7. **Solution Matrix.** Problems P1-P23 against the components; empty cells became the Gaps section.

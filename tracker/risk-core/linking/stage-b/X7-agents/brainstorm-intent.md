# X7 brainstorm intent: agents and the risk-and-sizing template

Derived from `.memlog.md` in this folder (headless run, 2026-11-03). Full hybrids: `expansion/X7-agents.md`.

## The intent in one paragraph

Agents help risk and sizing through a door with three surfaces and nothing else: **read** (risk state, ledger, receipts, journals, readings, search ledger), **propose** (expiring evidence that can only cut and that only a unit's own declared rule may read; effect-bound cards for everything else) and **run** (sandboxed replays, scenarios and checks, each counted as a trial). The core (guard, sizer, brakes, exits, kill switch) stays code on the node with no agent write path. Cuts can be fast and automatic; raises are slow, evidence-gated, and his: once as a pre-authorised rule, or per card. His attention is the scarce resource, so one hard budget of cards per day governs every agent.

## What must hold

1. Every tool and app operation declares a direction: read, propose, cut, raise, money. Agents get the first three. The host already answers `manage` operations only to him.
2. Agent evidence is a declared input of the unit's own rule. Missing evidence means no change. This keeps the letter of ruling 2; his reading of ruling 2 is still question 1.
3. Every card is rendered from its exact effect, signed, executed from storage, and re-checked at use time.
4. Every trial counts: one search ledger for alpha and risk search. Agents keep a cut channel in a class only while they beat a matched random cutter.
5. Growth has equal standing: a restore ladder, an advocate agent, and money both ways on every card.
6. One implementation of the tools, shipped as a risk mini app with an MCP server, so the Lab, the copilot, outside MCP agents and the future department use the same door.

## Decisions taken in the run

- The roundtable kept one hard attention limit; agent credit only ranks the queue.
- Slow isolation ships as a card first; it applies automatically on confirmed evidence only once the node has class and region scopes.
- Autonomy demotes on agent-caused signals; book drawdown only freezes new grants.
- The rationale-blind checker and the challenger stay separate roles.
- Money MCPs stay inside the trading-node app; the build session's cTrader MCP needs checking.

## Questions for him

Automatic cuts on agent evidence (ruling 2); automatic isolation on confirmed evidence; pre-authorised restore rules; cards per day; a reserved unit type for agent traders.

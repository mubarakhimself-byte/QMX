<alphaxiv-thinking-title title="Discovering papers on algorithmic trading" />

Research in algorithmic trading has shifted significantly toward **Deep Reinforcement Learning (DRL)**, **Large Language Models (LLMs)**, and **GPU-accelerated simulations**. Recent work focuses on making these systems more robust to high-frequency market noise and improving their reasoning capabilities through agentic frameworks.

| Paper | Key Contribution |
| :--- | :--- |
| [Trading-R1: Financial Trading with LLM Reasoning via Reinforcement Learning](https://www.alphaxiv.org/abs/2509.11420) | Enhances financial trading by integrating LLM reasoning with RL to improve interpretability and decision-making trust. |
| [MacroHFT: Memory Augmented Context-aware Reinforcement Learning On High Frequency Trading](https://www.alphaxiv.org/abs/2406.14537) | Introduces a memory-augmented RL framework specifically for the high-volatility cryptocurrency HFT market. |
| [JaxMARL-HFT: GPU-Accelerated Large-Scale Multi-Agent Reinforcement Learning for High-Frequency Trading](https://www.alphaxiv.org/abs/2511.02136) | Provides a high-performance simulation environment using JAX for large-scale multi-agent HFT experiments. |
| [QuantAgent: Price-Driven Multi-Agent LLMs for High-Frequency Trading](https://www.alphaxiv.org/abs/2509.09995) | Explores multi-agent LLM systems for reasoning and execution in high-frequency trading environments. |
| [The Evolution of Reinforcement Learning in Quantitative Finance: A Survey](https://www.alphaxiv.org/abs/2408.10932) | A comprehensive survey reviewing over 160 publications on RL applications in finance, identifying key trends and gaps. |
| [FinRL-X: An AI-Native Modular Infrastructure for Quantitative Trading](https://www.alphaxiv.org/abs/2603.21330) | Presents a modular infrastructure designed to unify data processing, backtesting, and deployment for AI-driven strategies. |
| [Label Unbalance in High-frequency Trading](https://www.alphaxiv.org/abs/2503.09988) | Addresses the technical challenge of imbalanced datasets in HFT prediction models to improve signal reliability. |
| [A Deep Reinforcement Learning Approach to Automated Stock Trading, using xLSTM Networks](https://www.alphaxiv.org/abs/2503.09655) | Utilizes extended LSTM (xLSTM) architectures to capture longer-term market dependencies more effectively than standard LSTMs. |

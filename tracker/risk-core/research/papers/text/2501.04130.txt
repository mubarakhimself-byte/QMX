Abstract
Multi-stream sequential change detection involves simultaneously monitoring many data
streams and raising an alarm when their distributions change. We study the multiple testing
issues that arise naturally in this setting. We first point out a fundamental tension between the
criteria used in change detection and multiple testing: any procedure with finite average run
length (ARL) must have worst-case false discovery rate (FDR) and family-wise error rate equal
to one. Given this conflict, we find a middle ground by introducing theerror over patience(EOP)
class of Type I error metrics, which measure error relative to expected monitoring time. To control
the EOP, we propose procedures combining e-detectors, which generalize Shiryaev-Roberts and
CUSUM methods, with the recent e-Benjamini-Hochberg and e-Bonferroni methods for multiple
testing. Our EOP guarantees hold uniformly over changepoints and stopping times with finite
expectation, allowing dependence when each e-detector remains valid using information from all
streams. If finite ARL is forfeited, using e-processes instead yields ordinary FDR and per-family
error control at stopping times. We also prove power and delay bounds for Gaussian changes,
establish first-order minimax optimality, and compare our procedures with existing methods in
numerical experiments.

The unknown time of the change is called thechangepoint. A common metric considered in this
setting is the average run length (ARL), which is the expected time until a false alarm when there is
no change. One typically seeks change detection algorithms that have a small detection delay while
guaranteeing a lower bound on the ARL.
The multi-stream setting is concerned with detecting changes in many streams. We do not
assume that changes, if any, occur at the same time across streams. An algorithm which is effective
in the single-stream setting may not be good when deployed without alteration on each of the
multiple streams. This is because we would only obtain a guarantee on the per-stream ARL, but not
on metrics that evaluate the reported changes across streams.
For instance, we may want control over the false discovery rate (FDR), which is the expected
proportion of detections which are false. False detections may be costly, and one may consequently
desire to control the family-wise error rate (FWER), the probability that at least one reported
detection is false, or the per-family error rate (PFER), the expected number of false detections.
These criteria concern which streams are reported to have changed. We therefore study algorithms
that identify changed streams, in addition to detecting that a change has occurred somewhere.
We consider monitoring algorithms which report a set of streams at each time, and allow the user
to decide when to stop. Astopping timeis a rule for stopping that uses only information available
at the time of the decision. For example, a user might stop when the first change is declared, when
several changes are declared, or when there are insufficient resources to continue monitoring. We
seek error guarantees that hold for any such choice, including rules that use observations from all
streams.
We first show that finite global-null ARL prevents FDR or FWER control below one at every
stopping time. Under theglobal null, meaning that no stream ever changes, a finite ARL implies
that a first alarm occurs almost surely. If we stop at that alarm, all the reported changes are false.
Thus, the worst-case FDR and FWER over stopping times and choices of changepoints equal one.
This gives a fundamental tension between finite ARL and error control at arbitrary stopping times.
Controlling the error at each fixed time is a different requirement.

To construct procedures with these guarantees, we use e-detectors (Shin et al., 2024). An
e-detectoris a nonnegative process whose expected value at a stopping time is at most the expected
stopping time under the null hypothesis. E-detectors generalize the classical Shiryaev–Roberts
(SR) and cumulative sum (CUSUM) procedures to nonparametric settings: the SR statistic and a
likelihood-ratio CUSUM statistic are particular examples. Ramdas (2026) relaxes this expectation
condition to obtain a universal representation of change detection procedures satisfying an ARL
constraint. We use the stopped expectation bound to control EOP at data-dependent reporting
times.
We construct e-d-BH by combining the streamwise e-detectors with the e-Benjamini–Hochberg
(e-BH) procedure of Wang and Ramdas (2022). We also construct e-d-Bonferroni, which applies
a common threshold to the e-detectors. With e-d-BH, the evidence in several streams can lower
the threshold for declaring a change, allowing streams with less evidence to be included. We prove
that the two procedures control FDR EOP and PFER EOP, respectively, and derive lower bounds
on the expected time to false declarations. We do not require independence across streams: each
e-detector must instead remain valid when stopping can use observations from all streams. We state
this condition precisely in Section 3.1 and give Gaussian and nonparametric examples in Section D.1.
We then analyze detection in a Gaussian mean-change model in Section 4. We prove finite-sample
bounds on the number of observations sufficient to detect a prescribed fraction of the changes, and
use these bounds to control expected delay. The bounds explain how having more changed streams
reduces the evidence required by e-d-BH. For independent streams and a fixed number of streams,
we also prove a matching first-order minimax lower bound under the FDR EOP constraint. Both
e-d-BH and e-d-Bonferroni attain this bound as the error level tends to zero. This establishes their
3
leading-order efficiency for identifying changed streams, while leaving room for differences at finite
error levels.
In Section 5, we compare the performance of our EOP-controlling procedures with existing
frequentist and Bayesian identification methods. We evaluate the errors and true discoveries in
each method’s first report, and include both fixed changepoints and changepoints generated from
the Bayesian prior. We find that e-d-BH reports more true changes and reports sooner than a
time-adjusted CUSUM procedure in the fixed-change experiments; Bayesian procedures benefit when
the data follow their prior. We also show that the gain over e-d-Bonferroni persists with heavy-tailed
observations and dependent counts. Finally, we compare with classical global detectors at a common
ARL target. These methods can combine evidence to raise an alarm sooner without deciding which
streams to report, and the comparison helps explain the additional cost of identification.
We give the proofs in Appendices A to C, following the order of the main results. In Appendix D,
we discuss other discounts and further consequences of the error bounds.
1.1 Related work
Classical multi-stream change detection often asks when to raise a global alarm, subject to a lower
bound on the no-change ARL. Examples include the scalable CUSUM procedures of Mei (2010), the
mixture procedures of Xie and Siegmund (2013), and the asymptotic analysis of Chan (2017). These
methods can combine moderate evidence from many streams to detect a change quickly, and their
model assumptions permit detailed analyses of detection delay. We study the additional problem of
identifying which streams changed. Controlling false discoveries in the reported set can require more
evidence than raising a global alarm.
Multiple-testing criteria have also been studied in change detection. Bodenham and Adams
(2017) discuss false detections and changes correctly detected in a single stream. For independent
streams, Gandy and Lau (2013) compute p-values from the null distribution of bounded CUSUM
statistics and apply BH to control FDR at each fixed time. In the parallel setting, Chen et al. (2020)
study FDR-oriented detection under a Bayesian model, while Lu et al. (2022) develop a broader
framework for balancing detection errors and utility. Chen and Li (2023) control the expected
proportion of changed streams among those still being monitored, with declarations permanently
removing streams. The latter two works derive optimality results under their assumptions on the
changepoints and data distributions. We treat changepoints as unknown fixed quantities and prove
4
bounds that hold for every choice of these times; our error criterion scales with expected monitoring
time.
The work of Lee et al. (2026), whose preprint appeared after the first version of our paper, is
especially close to ours. They usee-values, nonnegative statistics with null expectation at most
one, to control FDR at each deterministic time in a sensor network whose membership can change.
For a fixed set of sensors, their basic SHEREF rule is a special case of our fixed-time procedure
in Section 3.3: it applies e-BH to SR statistics divided by the current time. Their framework
additionally handles sensor entry and removal, and develops methods to improve power. Our main
result uses the unnormalized e-detectors to bound error divided by expected monitoring time at an
arbitrary stopping time.

2.2 Error over patience
We first show that any procedure with finite global-null ARL cannot control FDR or FWER below
one at every stopping time. Under the global null, every declaration is false. A user who waits for
the first declaration will therefore receive a false discovery, however long the procedure takes to
make it. The same reasoning applies when the user waits for at leastη declarations. We state this
observation below.

2.3 Run length when some streams change
We next show how EOP control gives run-length guarantees when some streams change. The
global-null ARL only describes a system in which no stream changes. If we raise an alarm after
declaring at least η streams, we may instead want a long expected wait whenever fewer thanη
streams actually change. This is the same reporting ruleτ ∗η (φ)as in Theorem 2.1: it counts all
declarations and does not require knowledge of which are false.

3 Multiple testing with e-detectors
We now construct procedures that control EOP. We maintain one e-detector for each stream, using
it to measure evidence that the stream has changed. We then apply a multiple testing rule to theK
detector values at each time. We first describe how to construct the individual detectors, then prove
that the resulting reporting rules control false discoveries across streams and stopping times.
3.1 Constructing e-detectors
We first give some background on e-values and e-processes. Ane-valuefor a null hypothesis is a
nonnegative random variable with expectation at most one under every distribution in the null. An

e-process yields an e-value whenever it is stopped. One can think of it as accumulating evidence
against the null; ideally, it grows quickly under an alternative. See Ramdas et al. (2023) for further
background.

Infinite ARL is compatible with Theorem 2.1, whose premise is finite ARL. It does not by itself
bound the probability of ever making a false declaration. We next obtain this additional guarantee
by changing the evidence processes themselves.

5.4 Global detection
Identifying streams is more demanding than declaring that some change has occurred. To compare
the latter task, we add Sum-CUSUM (Mei, 2010), the scan and mixture procedureT2 of Xie and
26
Siegmund (2013), and the transformed-CUSUM procedure of Chan (2017). We fit thresholds to
global-null ARL 1000 and validate them on independent runs. We use 50 streams, shifts of size 0.4
or 0.75, and either 5 or 25 changes at time 101.
We find that the global procedures usually raise an alarm sooner, particularly when many streams
change. They can combine evidence across the changed streams without deciding which ones to
report. We use this comparison to complement the identification lower bound in Theorem 4.2. A
common ARL also allows different probabilities of an alarm before the change. We report those
probabilities, validated ARLs, conditional delays and the methods’ tuning choices in Section E.3.
6 Discussion
We propose EOP as a Type I error metric for sequential monitoring, and construct e-d-BH and
e-d-Bonferroni to control it. The metric allows the user to choose when to report while relating
the permitted error to expected monitoring time. We prove guarantees under the global-filtration
condition (8), allowing dependence within and across streams, and show that they imply lower bounds
on the expected time to false declarations. Thus the procedures provide run-length guarantees as
well as bounds on errors in the set reported at a stopping time. We also show how normalizing the
e-detectors gives FDR control at each fixed time, and how using e-processes gives FDR control at
stopping times without the patience denominator.
For Gaussian changes, we prove finite-sample bounds on the observations sufficient to identify a
prescribed number of changes. These bounds quantify the effect of the shift size and the number of
changed streams on detection. For independent streams, we also prove a matching first-order delay
lower bound under the FDR EOP constraint. Both procedures attain the minimax leading term as
the error level tends to zero with the number of streams fixed. The lower bound requires control
over every changepoint configuration: evidence that other streams have changed cannot by itself
justify declaring a change in a stream that may still be null.
We find that the EOP-controlling procedures also have useful identification power in the experi-
ments. e-d-BH reports more true changes and reports sooner than the time-adjusted Gandy–Lau
procedure in the fixed-change settings. The comparisons also show the benefit of information supplied
to competing methods: Bayesian procedures can report sooner when the data follow their changepoint
prior, and global scan and aggregation methods can combine evidence without identifying the affected
streams. Between our two procedures, we find that the BH threshold improves identification over
27
Bonferroni, including with heavy-tailed observations and dependent counts. We report ordinary
errors alongside these gains, since controlling different error criteria does not imply the same achieved
FDR.
Our optimality result fixes the number of streams. Studying a growing number of streams may
distinguish the BH and Bonferroni thresholds beyond the leading term proved here. Another question
is how much detection delay is needed when the post-change distribution must be estimated. We
also allow one changepoint per stream and evaluate the current set of declarations. To extend the
guarantees to permanent removal of declared streams or repeated changes, we would need to account
for errors accumulated over successive decisions.

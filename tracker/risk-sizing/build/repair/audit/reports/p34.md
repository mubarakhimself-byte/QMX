VERDICT: REPAIR

## 1. What this part is for

This part makes a unit's history readable and lets agents help in the slow lane. Every app on a machine only appends to its own journal files. The host's records job files them into the machine's market store each minute, and on This PC it also pulls node records home and turns closed trades into Library items and paper scores. Agents read through `journal_query`, `readings_query` and `instrument_get`, and write only notes. A workflow's agent step can now write files inside its own attempt folder, and only declared files leave it. The MIS is a mini app that reads the store, respects his holdout, and publishes readings. It moves the old reading blocks into one shared package and adds calendars for every market. Nothing here reaches an order.

**Invariants that hold.** A unit stands alone from the MIS. One reader rule: everything reads streams with the committed reader, and the stream files stay byte for byte. Apps never open the door; the MIS only reads the store. Only the host writes `road/`. Agents read readings only through `readings_query`, since `journal_query` excludes that stream at the tool. No `bot` or `strategy` is written. The MIS never reads a sealed month, and missing facts seal everything. No reading is rewritten.

**Invariant that fails.** "Each closed paper, demo and live round trip" becoming one `trade` item (journals.md section 4), on the real path.

**Scope.** No code beyond what sections ask, apart from the MIS's small `round` and `board` operations, which PR c09 declares and which earn their place. Neither is a finding. The never-run regime modules are p34-14.

## 5. What is fine

- **The harvester's filing logic:** closed months until frozen, open months by class, skipping unchanged streams, leaving files untouched with a line in flight. Re-committing identical rows after a crash cannot freeze an open month, because the store refuses to freeze before month end (`series.py:659`). The module's docstring overstates that risk, which is harmless.
- **`Pull`:** fingerprint checked before commit, watermark never passes a failure, confirm only what this door holds frozen, a corrupt state file set aside.
- **The AGW policy and overlay handling:** path escape, relative paths, pathless writes, chat closed before the folder goes on Windows.
- **`readings_query` and `instrument_get`:** cursor order, holdout refused by name, `data_ends_at`, version in force.
- **Calendars:** the session rule across clock-change weeks, and the sweep test uses a hand-written offset table, so it does not grade zoneinfo with zoneinfo. I checked the NYSE holiday dates for 2026 and 2027 by hand and they are right.
- **The C-08 move:** clean, with no compatibility layer left.
- **The MIS's own core once configured:** seal, restart without double publishing, shadow kept off the board, bad arguments answered.
- **`paper.py`:** the scoring is correct arithmetic. Its numbers are not graded here.
- **`status` and `board` as `domain_write`:** looks odd, is correct. The manifest forbids `read` on an operation with instance state, and the contract says so.

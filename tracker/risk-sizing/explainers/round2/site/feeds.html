The feed pool

One feed keeper per broker connection subscribes once per symbol and fans each price out to every unit, guard and the router on that machine.

  • proposedOne subscription per symbol, never per unit: 200 units on 60 symbols = 60
  • proposedLast-value cache: a starting unit reads the latest price at once
  • proposedWarm-up comes from our recorder, keeping the broker's history limit for gap repair
  • proposedThe router is a reader, never in the data path

PC and node take turns

On cTrader, the PC and the node shouldn't both hold the live connection.

  • foundcTrader's docs say you should open one demo and one live connection per app: advice, not a hard cap
  • foundA second machine refreshing the same sign-in logs the first one out
  • proposedThree ways: a lease, two apps (two sign-ins), or node = live and PC = demo
  • improveA one-minute test on demo settles the socket question

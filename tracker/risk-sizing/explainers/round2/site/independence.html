Round 2 · 03 · Independence proposed

Units stand alone

Everything a unit needs to trade sits on its own machine. The router, the PC link and the Library are extras. Pull a cable and see.

  • proposedHard needs, all local: spec, your admission, feed, guards, journal
  • proposedSoft: router offers and market labels. The PC and Library aren't needed to trade
  • foundThe shipped node already shows 'unreachable since …' and keeps last values
  • foundThe news guard already fails entries closed while exits continue
  • foundThe Library already has an outbox for writes that can't go yet

Units reading market labels

You leaned toward units reading both live data and the market labels. Four ways to do it:

aNeverUnits read raw prices only; labels serve the router and guards. Total independence, but each unit recomputes things like 'is spread wide?'.
bOptional, with a declared fallbackThe unit lists the labels it uses and what to do without each one. QMB tests it both ways.
c'Compute where you areLabels are library code. The unit reads the shared copy, or computes it itself with the same code when that copy is missing. Works for rule labels, not trained models.
cFreely, like any feedSimplest to write, but an outage silently changes behaviour unless paired with c'.

One clock per job

Round 1 saidThe plan expires after 5 trading days; then no new entries anywhere.
Round 2 optionNo single clock. Each job gets its own, so a scalper never waits on a 5-day plan.

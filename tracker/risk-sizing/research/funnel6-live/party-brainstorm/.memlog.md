- (technique) started First Principles Thinking (domain: node setup)
- (idea) B001 A trading server is one more kind in the shipped connect dialog, reusing its runner: his cards first, then checked rerun-safe steps, one place row written last.
- (idea) B002 Provider-API wizard: he pastes a provider token once, QMX creates the server, installs, then deletes the token. Token lifetime is a number.
- (idea) B003 No-token wizard stays the default: he rents by hand (today's card), QMX does everything after the address.
- (idea) B004 Cloud-init paste: QMX prints one text block, he pastes it into the provider's user-data box, the server builds itself and calls home over the private network.
- (idea) B005 Region picker by measured latency: the wizard times a round trip to each broker's trade host from candidate regions before he pays.
- (idea) B006 One image, two roles: the QMX host package gains a trading role, instead of a separate QMN deploy with its own paths and observability.
- (idea) B007 Places gain a can-trade capability beside can-run, so placement vocabulary covers trading servers without a new concept.

- (idea) B009 Size suggestion: the wizard reads how many units and data kinds are admitted and proposes a server size; the size table is a number.
- (idea) B010 Retire-a-node wizard: units move back to paper on the PC, the node's own broker app grant is revoked, the server is deleted through the provider.

- (idea) B012 Second node = clone this node in another provider; no second wizard.

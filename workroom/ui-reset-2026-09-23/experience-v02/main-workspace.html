Reading and density

System sans. Base 14 / 21. Supporting text 12 / 18. Titles 22 / 33. Preserve readable labels in dense workspaces.

Spacing steps: 4, 8, 12, 16, 24, 32 px. Control radius 6 px; grouped surfaces 8 px.

Primary actions stay visible. Supplementary information can disclose progressively.

Actions and focus

Use explicit verbs. Keep focus visible. Disabled controls need a visible reason. Samples here are inactive; use the workspace to try actual interactions.

Attachment picker: modal dialog, Escape closes, focus returns to Attach.

Context is inspectable

A reference shows name, source, availability and lifetime. Removing it changes future context; earlier messages retain their sent reference record.
